# Discord

Benachrichtigungen als Embed in einen Discord-Kanal über einen Webhook.

## Einrichten

1. In den **Kanaleinstellungen** unter **Integrationen** → **Webhooks** einen neuen Webhook anlegen.
2. **Webhook-URL kopieren** und hier eintragen (`https://discord.com/api/webhooks/…`). Wer die URL kennt, kann in den Kanal schreiben: SerMon speichert sie verschlüsselt und zeigt sie nie wieder an.

## Darstellung

Das Embed hat die Farbe der Stufe, die Werte des Alerts und einen Link zum Node in SerMon. Nachrichten von SerMon erwähnen niemanden, auch nicht mit `@everyone` in einem User-Namen.
