# Microsoft Teams

Benachrichtigungen als Karte in einen Teams-Kanal über einen Workflow.

## Einrichten

1. Im Teams-Kanal **Workflows** öffnen und die Vorlage **Beim Empfang einer Teams-Webhookanforderung in einem Kanal posten** wählen.
2. Team und Kanal bestimmen und den Workflow speichern.
3. Die angezeigte URL hier eintragen. Sie enthält eine Signatur und wirkt wie ein Passwort: SerMon speichert sie verschlüsselt und zeigt sie nie wieder an.

Die alten Office-365-Connectors stellt Microsoft ein; nutze den Workflow.

## Darstellung

Die Karte zeigt den Titel in der Farbe der Stufe, die Werte des Alerts und einen Button zum Node in SerMon. Werte der Server erscheinen als reiner Text, ohne Markdown.
