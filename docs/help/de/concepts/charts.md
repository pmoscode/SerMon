# Charts und Zeitraum

Alle Charts einer Seite zeigen denselben Zeitraum und folgen gemeinsam dem Mauszeiger.

## Bedienen

- **Zeitraum wählen:** über die Schaltflächen (15 Minuten bis 30 Tage). Der Zeitraum endet immer jetzt und läuft mit.
- **Hineinzoomen:** mit gedrückter Maustaste einen Bereich in einem Chart markieren. Alle Charts der Seite zoomen mit.
- **Zurück:** Doppelklick in einen Chart oder „Zoom zurücksetzen“.

## Auflösung

Für die letzten 15 Minuten gibt es Werte im Sekundentakt, danach 10-Sekunden-, Minuten- und Stundenwerte. Bei langen Zeiträumen zeigt ein Punkt den Mittelwert eines Abschnitts; kurze Spitzen fallen dabei flacher aus.

## Lücken

Eine Lücke in der Linie heißt: Für diese Zeit liegen keine Werte vor, etwa weil der Server aus war oder der Agent keine Verbindung hatte. Gepufferte Werte trägt der Agent nach, sobald er wieder verbunden ist.
