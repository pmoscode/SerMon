# MTTR

Die mittlere Zeit vom Auslösen eines Alerts bis zu seiner Behebung (Mean Time To Resolve).

## Einordnung

- Sie umfasst Bemerken, Suchen und Beheben. Noch aktive Auslösungen zählen nicht mit.
- Sehr kurze Zeiten bei vielen Auslösungen deuten auf Alerts, die von selbst wieder verschwinden – dort hilft eine längere Dauer der Regel.
