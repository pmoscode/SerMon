# sudo-Fehler

sudo-Aufrufe mit falschem Passwort und Aufrufe von Usern, die sudo nicht benutzen dürfen, im Zeitraum.

## Einordnung

- Einzelne Tippfehler beim Passwort sind normal.
- Viele Fehler oder Versuche von Usern ohne sudo-Recht können bedeuten, dass jemand mit einem übernommenen Konto mehr Rechte sucht.

## Nächste Schritte

1. In der Tabelle nachsehen, welcher User es war und welches Ziel er wollte.
2. Mit der Person klären, ob die Versuche von ihr kamen; sonst das Konto sperren.
