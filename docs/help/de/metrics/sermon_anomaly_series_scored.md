# Bewertete Metriken

Wie viele Serien des Nodes die Anomalie-Erkennung gerade bewertet (etwa CPU-Modi, Speicher, Disks, Interfaces).

## Einordnung

Bis zu 64 je Node. Fehlt eine Serie, hat sie noch zu wenig Historie für ihre Stunde der Woche, oder der Node lernt noch.

Metrik: `sermon_anomaly_series_scored`
