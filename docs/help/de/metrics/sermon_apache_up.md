# Apache erreichbar

1, wenn die Statusseite gelesen wurde, 0, wenn Apache nicht antwortet (gestoppt, abgestürzt oder die URL zeigt ins Leere).

## Einordnung

Vom Modul `apache` (`server-status?auto`). Raten ab dem zweiten Lauf; nach einem Neustart von Apache setzen sie einen Lauf aus.

Metrik: `sermon_apache_up`
