# Endpunkt erreichbar

1, wenn der Endpunkt mit einem erwarteten Status antwortete, sonst 0.

## Einordnung

Vom Modul `http_check`; Label `target` ist das konfigurierte Ziel (eine URL ohne Query bzw. `host:port`). Ziele nur unter dem lokalen Veto des Hosts (`module_targets`).

Metrik: `sermon_http_check_up`
