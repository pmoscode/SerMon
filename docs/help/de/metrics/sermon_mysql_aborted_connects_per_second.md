# Gescheiterte Verbindungen

Fehlgeschlagene Verbindungsversuche je Sekunde (falsches Passwort, fehlende Rechte, Zeitüberschreitung).

## Einordnung

Gelesen vom Modul `mysql` (MySQL und MariaDB) mit einem User mit `PROCESS` und `REPLICATION CLIENT` (MariaDB: `REPLICA MONITOR`).

Metrik: `sermon_mysql_aborted_connects_per_second`
