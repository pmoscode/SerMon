# Laufende Verbindungen

Verbindungen, die gerade eine Anweisung ausführen (`Threads_running`). Dauerhaft hoch: der Server kommt nicht nach.

## Einordnung

Gelesen vom Modul `mysql` (MySQL und MariaDB) mit einem User mit `PROCESS` und `REPLICATION CLIENT` (MariaDB: `REPLICA MONITOR`).

Metrik: `sermon_mysql_connections_running`
