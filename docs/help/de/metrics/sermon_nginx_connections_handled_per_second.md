# Bearbeitete Verbindungen

Bearbeitete Verbindungen je Sekunde; gleich den angenommenen, solange nginx genug Verbindungen frei hat.

## Einordnung

Vom Modul `nginx` (stub_status). Raten ab dem zweiten Lauf; nach einem Neustart von nginx setzen sie einen Lauf aus.

Metrik: `sermon_nginx_connections_handled_per_second`
