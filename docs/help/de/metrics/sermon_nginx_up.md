# nginx erreichbar

1, wenn die stub_status-Seite gelesen wurde, 0, wenn nginx nicht antwortet (gestoppt, abgestürzt oder die URL zeigt ins Leere).

## Einordnung

Vom Modul `nginx` (stub_status). Raten ab dem zweiten Lauf; nach einem Neustart von nginx setzen sie einen Lauf aus.

Metrik: `sermon_nginx_up`
