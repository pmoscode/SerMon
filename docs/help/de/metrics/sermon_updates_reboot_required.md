# Neustart nötig

1, wenn der Node laut seinem letzten Bericht einen Neustart braucht, damit installierte Updates wirken; sonst 0.

## Einordnung

Meist nach einem neuen Kernel oder Bibliotheken wie libc. Seit wann, zeigt
[Neustart nötig seit](help:metrics/sermon_updates_reboot_required_seconds).

Metrik: `sermon_updates_reboot_required`
