# Neustart nötig seit

Wie lange der Node schon einen Neustart braucht, ab dem ersten Bericht, der ihn verlangte; 0 ohne.

## Einordnung

Die Standardregel warnt nach einem Tag und wird nach 7 Tagen kritisch. Ein Neustart (von Hand oder durch die
Update-Policy mit autoReboot) setzt den Wert mit dem nächsten Bericht auf 0.

Metrik: `sermon_updates_reboot_required_seconds`
