# Alter des ältesten Security-Updates

Seit wann das älteste noch offene Security-Update des Nodes bekannt ist; 0 ohne Security-Updates.

## Einordnung

Die Zeit zählt ab dem Bericht, in dem SerMon das Update zuerst gesehen hat. Die Standardregel warnt nach 3 Tagen und
wird nach 14 Tagen kritisch. Wird das älteste installiert, fällt der Wert auf das Alter des nächsten.

Metrik: `sermon_updates_security_age_seconds`
