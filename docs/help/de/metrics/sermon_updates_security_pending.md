# Offene Security-Updates

Wie viele Security-Updates für den Node bereitliegen, laut seinem letzten Bericht.

## Einordnung

Normal ist 0 oder eine Zahl, die nach dem nächsten Update-Fenster wieder auf 0 fällt. Alpine kennt keine
Security-Updates, dort bleibt sie 0. Wie lange das älteste offen ist, zeigt
[Alter des ältesten Security-Updates](help:metrics/sermon_updates_security_age_seconds).

Metrik: `sermon_updates_security_pending`
