# Dashboards

Eigene Dashboards neben den eingebauten Ansichten: Lege die Charts, Werte, Log-Zeilen und Alerts nebeneinander, die du
brauchst, behalte sie für dich oder teile sie mit der Organisation.

## So geht's

- **Neu:** Titel eingeben und anlegen; das Dashboard öffnet sich im Editor. Es ist privat, bis du es teilst.
- **Geteilte** Dashboards sieht jedes Mitglied der Organisation. Jedes Widget zeigt nur Daten der Nodes, die der
  Betrachter sehen darf – Teilen gibt niemandem neue Rechte.
- **Ändern:** Der Eigentümer ändert, teilt und löscht ein Dashboard, ein geteiltes auch ein Admin aller Gruppen. Admins
  sehen private Dashboards anderer nicht.
- **Import:** Wähle die JSON-Datei eines exportierten Dashboards (höchstens 32 KiB). Sie wird dein privates Dashboard.
  Nodes und Gruppen darin müssen in dieser Organisation existieren und für dich sichtbar sein – eine Datei einer anderen
  Instanz oder Organisation wird abgelehnt; [Variablen](help:pages/dashboard) machen Dashboards übertragbar.

Höchstens 200 Dashboards je Organisation.
