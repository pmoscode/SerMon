# Discord

Notifications as an embed in a Discord channel through a webhook.

## Setup

1. In the **channel settings** under **Integrations** → **Webhooks** create a new webhook.
2. **Copy Webhook URL** and enter it here (`https://discord.com/api/webhooks/…`). Whoever knows the URL can post into the channel: SerMon stores it encrypted and never shows it again.

## Appearance

The embed has the colour of the level, the values of the alert and a link to the node in SerMon. Messages of SerMon mention nobody, not even with `@everyone` in a user name.
