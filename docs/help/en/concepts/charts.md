# Charts and time range

All charts on a page show the same time range and follow the mouse pointer together.

## Using them

- **Pick a time range:** with the buttons (15 minutes to 30 days). The range always ends now and moves along.
- **Zoom in:** drag across an area of a chart. All charts on the page zoom with it.
- **Back:** double-click a chart or use “Reset zoom”.

## Resolution

The last 15 minutes have a value per second, older data has 10-second, minute and hour values. For long ranges a point shows the average of a period, so short spikes look flatter.

## Gaps

A gap in a line means there are no values for that time, for example because the server was off or the agent had no connection. The agent sends buffered values once it is connected again.
