# Pending security updates

How many security updates are available for the node, according to its last report.

## Context

Normal is 0, or a number that drops back to 0 after the next update window. Alpine has no security updates, there it
stays 0. How long the oldest has been open shows the
[age of the oldest security update](help:metrics/sermon_updates_security_age_seconds).

Metric: `sermon_updates_security_pending`
