# Datenschutz / Data protection

Vorlage für die Datenschutz-Dokumentation von Betreibern einer SerMon-Instanz – keine Rechtsberatung.
Template for the data protection documentation of operators of a SerMon instance – not legal advice.

- Deutsch: [Vorlage zur DSGVO-Dokumentation](de/README.md) (maßgebliche Fassung)
- English: [GDPR documentation template](en/README.md)

Inhalt: Rollen (Verantwortlicher, Auftragsverarbeiter), personenbezogene Daten in SerMon, Verzeichnis der
Verarbeitungstätigkeiten, technische und organisatorische Maßnahmen, Löschfristen, Auftragsverarbeitung bei
Mandanten, Betroffenenrechte und bekannte Grenzen. Die Angaben entsprechen dem Code; wer Fristen, gespeicherte Daten
oder Schutzmaßnahmen ändert, passt diese Vorlage im selben PR an.
