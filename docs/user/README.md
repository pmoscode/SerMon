# Benutzerhandbuch / User guide

- Deutsch: [Benutzerhandbuch](de/README.md)
- English: [User guide](en/README.md)

Das Handbuch beschreibt die Abläufe und verlinkt für die Einzelheiten die Hilfetexte unter [`docs/help/`](../help/README.md),
die SerMon auch selbst anzeigt. Ein Test (`web/scripts/help.test.js`) prüft, dass jeder Link auflöst und beide
Sprachen dieselben Hilfetexte verlinken.

The guide describes the workflows and links the help texts under [`docs/help/`](../help/README.md) for the details,
which SerMon shows itself as well. A test (`web/scripts/help.test.js`) checks that every link resolves and that both
languages link the same help texts.
